OOH Alerting Classifier

Same four-tier escalation logic as ooh-alerting, running live. Try the demo values below or make up your own.

Try these examples

  • VIP: client-101, any subject, OOH checked → pages immediately
  • Priority: client-330, any subject, OOH checked → pages
  • Keyword: any client, subject "Server unreachable", OOH checked → pages
  • Skip pattern: subject "test ticket - server down - please ignore" → suppressed despite "down"
  • Watched: ticket ID tk-9001, any client → pages regardless of client tier
  • Business hours: uncheck the OOH box → never escalates, whoever the client is
